# Et forsvar for veldig skarpe økser

Min drøm er å være skikkelig smart og kunne skikkelig masse. Da må jeg være god til å lese, og til å skrive. Denne samlingen med verktøy er for å jobbe raskt og effektivt med tekst. I bunn og grunn handler det om Neovim (som er et program for å skrive og redigere tekst) og Quarto, som er et program for å ta teksten og lage dokumenttypene man trenger av dem (som nettsider i '.html' eller utskrevne dokumenter i '.pdf').

For å installere det må man kopiere denne mappa på en maskin som kjører Linux (eller Windows Subsystem for Linux), og kjøre skriptet fra mappa:

```sh
./install.sh
```

Da skjer det mye, men det viktigste er at man installerer Homebrew, som igjen laster ned alle programmene jeg har bedt om. Etter det kjører Stow,som kobler sammen innstillingene i denne mappa med systemet du kjører på.
